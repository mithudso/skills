# EMDR for Substance Use Disorder and Trauma Comorbidity

## Core Mechanism
- **Bilateral stimulation (BLS)**: Horizontal eye movements, auditory tones, or tactile taps delivered while patient briefly attends to traumatic material
- **Working memory overtaxation hypothesis**: Simultaneous demands of BLS + trauma recall compete for working memory capacity → reduces vividness and emotional intensity of the memory image
- **REM-analogy hypothesis**: BLS mimics REM-sleep eye movements → facilitates memory consolidation and integration into adaptive memory networks; sleep-improvement data partially support this
- **Inhibitory learning**: Functions similarly to exposure-based mechanisms — fear memory is activated then not reinforced, with new non-distressed associations installed via the Installation phase
- **Adaptive Information Processing (AIP) model**: Traumatic memories are "frozen" in raw sensory form, blocking normal processing; EMDR facilitates movement of the memory into the adaptive memory network where it becomes integrated, less charged, and accessible without dysregulation

## 8-Phase Protocol
| Phase | Function | SUD Relevance |
|---|---|---|
| 1 — History/Planning | Case conceptualization; target memory selection | Map trauma → first-use → relapse chain |
| 2 — Preparation/Stabilization | Teach containment, emotion regulation, grounding | **Most critical in SUD; significantly extended** |
| 3 — Assessment | Identify target image, negative cognition, SUD, VOC, emotion, SUDS, body location | |
| 4 — Desensitization | BLS sets while holding target; SUDS → 0 | Not initiated <4 weeks abstinence |
| 5 — Installation | Positive cognition installed (VOC → 7) | |
| 6 — Body Scan | Residual body tension cleared | |
| 7 — Closure | Containment if incomplete; safety plan | |
| 8 — Reevaluation | Review prior targets; assess new material | Monitor craving levels session-to-session |

SUDS = Subjective Units of Distress Scale; VOC = Validity of Cognition Scale

## SUD-Specific Adaptations

**Phase 2 Extension (critical gate):**
- Substance use often functions as maladaptive emotional regulation; processing trauma without first building emotion regulation skills removes the coping mechanism before replacing it
- Minimum stabilization before Phase 4: grounding techniques (5-4-3-2-1, container exercise), affect regulation skills, and therapeutic alliance sufficient to tolerate distress without using
- No active trauma desensitization (Phases 4–7) during acute withdrawal or <4 weeks post-use for stimulant/meth SUD; destabilization risk is high during neurobiological dysregulation

**Addiction Memory Processing (EMDR-AMP / Hase Protocol):**
- Extends standard EMDR to directly target addiction-specific memories: first-use memory, worst-use memory, craving moments, relapse memories
- These memories carry conditioned emotional valence (relief, euphoria, escape) that drives cue reactivity independently of PTSD memories
- BLS applied to craving cues and use memories reduces conditioned salience alongside trauma processing
- Distinct from PTSD trauma processing — targets appetitive conditioning, not fear conditioning

**Craving Cue Desensitization:**
- Patient imagines high-risk cue (drug paraphernalia, use environment, emotional state) while receiving BLS
- Mechanism parallels VR cue-exposure therapy: cue activated without reinforcement → extinction of conditioned craving
- Can be delivered in preparation phase before trauma processing begins

## Meth SUD + PTSD Comorbidity
- Trauma comorbidity prevalence: ~50–70% of people with meth SUD meet lifetime PTSD criteria; childhood trauma, sexual violence, and poly-victimization are most common antecedents
- Meth use commonly initiated as self-medication for PTSD hyperarousal, insomnia, and emotional numbing
- Meth-induced neurotoxicity (prefrontal cortex, hippocampus, anterior cingulate) impairs working memory and emotional regulation — both required for standard trauma processing
- EMDR's shorter processing windows (BLS sets of 24–50 movements, brief holds) may be better tolerated than Prolonged Exposure's extended narrative holds in patients with attention and working memory impairment
- Sleep disruption in meth-PTSD is multiply-sourced (PTSD hyperarousal + meth sleep architecture disruption); EMDR's documented sleep improvement effect (reduced nightmares, improved Stage 3/4) is clinically relevant

**Clinical staging for meth-PTSD:**
1. Detox + acute medical stabilization
2. Extended Phase 2 EMDR (4–8+ weeks): stabilization, regulation skills, therapeutic alliance
3. Addiction memory processing (EMDR-AMP) for use memories + craving cues — before PTSD trauma processing
4. PTSD trauma processing (Phases 3–8) for discrete traumatic events
5. Relapse prevention integration

## Evidence Base
- **2025 meta-analysis (PMC12484161, 14 studies)**: EMDR produced significant effects on craving (g = 0.55), PTSD (g = 0.69), depression (g = 0.64), anxiety (g = 0.72) in SUD populations
- **2023 meta-analysis (Journal of EMDR Practice and Research, 10 studies, N=561)**: EMDR effective for SUD treatment engagement and severity, comorbid PTSD and depression; craving reduction less consistent across studies
- **2024 meta-analysis (MDPI Brain Sciences, craving-focused)**: EMDR reduces substance craving in SUD populations; effect moderated by trauma comorbidity — greater craving reduction in PTSD+SUD than SUD-only
- **van den Berg et al. 2015 (RCT, N=34, PTSD+SUD)**: EMDR vs. CBT — non-inferior for PTSD reduction; EMDR group also showed SUD symptom improvement not seen in CBT arm
- **Hase et al. (4-case series, 12-month follow-up)**: Standard EMDR with AMP extension for alcohol/SUD+PTSD; sustained PTSD and SUD symptom reduction at 12 months
- No published RCT in methamphetamine-specific SUD+PTSD population as of 2025; meth participants included in heterogeneous SUD samples

## EMDR vs. Prolonged Exposure in PTSD+SUD
| Factor | EMDR | Prolonged Exposure |
|---|---|---|
| Homework burden | Low | High (daily recordings) |
| Narrative requirement | Brief focus on image | Extended trauma narration |
| Cognitive impairment tolerance | Better (short windows) | Harder (sustained engagement) |
| Evidence in SUD | Growing, 2+ meta-analyses | Less studied in SUD |
| Dropout | Generally lower | Higher in SUD populations |

No head-to-head RCT specifically in meth SUD+PTSD population exists; choice is typically driven by patient preference, cognitive capacity, and therapist training.

## Key Facts
- Phase 2 is the rate-limiting step in SUD populations — inadequate stabilization predicts treatment dropout and symptom exacerbation
- EMDR International Association (EMDRIA) 2021 practice guidelines recommend EMDR for comorbid PTSD+SUD
- EMDR-AMP (addiction memory processing) is a protocol extension, not a separate modality; delivered by EMDR-trained clinicians with SUD specialization
- BLS modality (eye movements vs. taps vs. tones) shows equivalent efficacy across trials; taps and tones useful for patients with trauma-related difficulty with direct eye contact
- Memory reconsolidation window (~6 hours post-reactivation) may explain why EMDR sessions require careful closure — incompletely processed memories are labile and dysregulating
