# Competency questions — technical-training-education

Family seeded by concept-family-explorer, 2026-06-11. Someone working technical
training, learning programs, and certification (MongoDB University as the domain
anchor) should be able to ask each question below and reach a skill.

- Which MongoDB University learning path, badge, or certification (Associate Developer, Associate DBA, Associate Atlas Admin, Associate Data Modeler) fits a given customer team, and how do I build a customer enablement plan around it?
- Which instructional-design framework (ADDIE, SAM, backward design, Gagné's nine events, 4C/ID) should structure a technical course or workshop, and how do I write measurable learning objectives for it?
- How do I apply learning science (cognitive load, retrieval practice, spacing, worked examples) so a training module actually sticks?
- How do I write valid, reliable quiz/exam items for a technical course (item writing, distractor design, formative vs summative assessment), and what do item difficulty/discrimination statistics tell me?
- What makes a technical certification program psychometrically sound and legally defensible (job task analysis, exam blueprinting, Angoff standard setting, item response theory, ISO/IEC 17024)?
- How do I measure training effectiveness and its business impact (Kirkpatrick levels, Phillips ROI, learning analytics, product-adoption lift)?
- Which delivery stack fits a course: LMS vs LXP selection, SCORM vs xAPI vs cmi5, hands-on lab/sandbox platforms, virtual instructor-led training?
- How do adaptive-learning and knowledge-tracing algorithms (Bayesian Knowledge Tracing, Deep Knowledge Tracing, IRT-adaptive testing, FSRS spaced-repetition schedulers) decide what a learner sees next?
- How should LLMs/AI be used in technical education (AI tutors, AI-generated courseware, AI-assisted grading, cheating-resistant assessment) without compromising validity or learning outcomes?
- How do digital credentials work (Open Badges 3.0, W3C Verifiable Credentials, Credly) and when should a program issue badges versus proctored certifications?
