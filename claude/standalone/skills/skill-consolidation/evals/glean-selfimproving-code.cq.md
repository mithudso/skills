# Competency questions — glean-selfimproving-code

Family: Glean enterprise-AI platform + applying learned optimizations to skills/workflows +
algorithmic code optimization + code auto-remediation + self-healing coding + LLM techniques.
Someone working this family should be able to ask each question and reach a HAVE or
researched skill (Step 8 coverage-saturation gate).

- How do I build an automated program-repair loop that localizes a fault, generates a patch, and validates it against tests? *(→ Automated Program Repair & Code Auto-Remediation — GAP-A)*
- How do I wire closed-loop auto-remediation so a recurring production error is fixed without a human in the loop? *(→ Self-Healing Systems & Autonomic Computing — GAP-B)*
- What is the MAPE-K control loop and how does autonomic computing apply to a self-healing service? *(→ Self-Healing Systems & Autonomic Computing — GAP-B)*
- Can an evolutionary or LLM-driven system discover a faster algorithm than the textbook one (AlphaDev, AlphaEvolve, FunSearch)? *(→ Algorithmic Code Optimization & AI Algorithm Discovery — GAP-C)*
- What is superoptimization and when is it worth it versus profiling or JIT tuning? *(→ Algorithmic Code Optimization & AI Algorithm Discovery — GAP-C)*
- How do I systematically distill a learned optimization from a session into a reusable skill or workflow? *(→ Self-Improving Skill Libraries / Experience-to-Skill Distillation — GAP-D)*
- How do I integrate Glean's Assistant and Agents into an enterprise RAG / agentic-search workflow? *(→ glean-dev / Glean AI layer — GAP-E)*
- How do I search company knowledge from the CLI or via the Glean MCP server? *(→ glean-dev — HAVE)*
- Which prompt-optimization algorithm (APE/OPRO/MIPROv2/GEPA/TextGrad) should I use to improve a production prompt? *(→ prompt-deep-optimizer / prompt-helper-optimizer — HAVE)*
- How do coding agents apply edits and run a plan→edit→test→repair self-repair loop? *(→ coding-agents — HAVE)*
- How do I optimize and quality-gate a Claude Code skill, and apply learned fixes back to it? *(→ skill-optimizer / claude-code-skills / continuous-learning-v2 — HAVE)*
