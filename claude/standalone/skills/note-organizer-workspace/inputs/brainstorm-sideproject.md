app idea dump - trail conditions app

hikers never know current trail conditions. alltrails reviews are weeks old
core idea: waze for trails. recent-condition reports from people actually on the trail
report types: mud, snow/ice, downed trees, water crossings, crowding, trail closure
offline first!! no signal on trails. queue reports, sync when back in range
maybe gamify? points for reports? hmm feels wrong for the outdoors crowd
photo with every report, auto-timestamp + GPS from exif
what if reports expire? snow report from 3 weeks ago is noise. auto-decay by report type - mud expires fast, downed tree stays til someone clears it
revenue?? premium tier with weather overlay? partnerships with parks depts?
parks depts might WANT this data - trail maintenance prioritization. sell them a dashboard
crowding reports could smooth out trailhead parking chaos
seed problem: app is useless empty. cold start. maybe scrape recent alltrails/reddit mentions as seed data? gray area legally
offline maps too? no thats scope creep, link to gaia/caltopo
the expire-by-type thing is the differentiator i think. nobody does freshness right
verification: multiple reports agreeing = confidence score. single report = "unconfirmed"
name ideas: trailpulse, freshtracks, trailcheck. freshtracks is probably taken by a ski thing
what about liability? someone trusts a "water crossing passable" report and drowns. TOS + "conditions change" disclaimers everywhere, never say "safe"
mvp: ios only, 3 report types (mud, snow, blockage), one metro area (denver? seattle?), no accounts - device id only
seattle better, year round conditions variance
