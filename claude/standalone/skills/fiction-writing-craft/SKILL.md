# Fiction Writing Craft

Hub for the craft of writing fiction: structure, scene-level technique, and
character psychology as a **writer's tool**, not a clinician's. This hub is
about rendering plot and interiority on the page convincingly — not about
diagnosing or treating anything. When the concept tree already has the
clinical/mechanistic version of a topic (trauma neuroscience, emotion
regulation), that coverage stays in `psychology-stress-trauma` /
`emotion-and-affect-psychology`; this hub's references cross-link to it for
the underlying science and focus on **portrayal**: what to put on the page so
a reader believes it.

## When to use this skill

See `whenToUse` above. Typical asks: "how do I structure a mystery plot",
"what's the difference between story and plot", "how do I show a character
having a panic flashback without narrating a DSM entry", "give me a beat
sheet for a romance subplot", "how do I make an action scene not read like a
grocery list of movements".

## When NOT to use this skill

See `whenNotToUse` above and the SKIP line in the description. The single
highest-risk collision is `writing-expert`'s `storytelling-and-narrative`
reference, which covers **business** narrative (QBR arcs, StoryBrand,
before/after/bridge for customer comms) — not literary fiction. If the ask
names a customer, account, product, or QBR, route to `writing-expert`; if it
names a character, scene, manuscript, or genre, it belongs here.
