# Evergreen notes compound

**Evergreen notes** (Matuschak): notes should be concept-oriented, not source-oriented. A second source on the same concept lands on the *existing* note, and the two compound over time. Give notes claim-like titles — "like APIs" (stable, reusable).

Source: Matuschak.

Note: this is the method this collection now applies — each concept above is one accreting note that the next reading can extend.
