# NC Structured Sentencing

**Educational only, NOT legal advice.** Consult a licensed NC attorney for specific matters.

North Carolina's Structured Sentencing Act (G.S. Chapter 15A, Article 81B) governs all felony and misdemeanor sentences for offenses committed on or after October 1, 1994. The system ties every sentence to two axes: offense class and prior record level.

## Felony Classification (Classes A–I)

| Class | Severity | Examples |
|---|---|---|
| A | Most serious | First-degree murder |
| B1 | | First-degree rape, kidnapping |
| B2 | | Second-degree murder |
| C | | First-degree kidnapping |
| D | | Voluntary manslaughter |
| E | | Felonious assault inflicting serious injury |
| F | | Felony breaking and entering |
| G | | Felony larceny |
| H | | Felony possession of controlled substance |
| I | Least serious | Worthless check (felony threshold) |

Unclassified felonies default to Class I. Offense classification appears in each crime's individual statute.

## Prior Record Level — Felonies (G.S. 15A-1340.14)

Points accumulate from all prior felony and qualifying misdemeanor convictions:

| Prior Conviction | Points |
|---|---|
| Class A felony | 10 |
| Class B1 felony | 9 |
| Class B2, C, or D felony | 6 |
| Class E, F, or G felony | 4 |
| Class H or I felony | 2 |
| Class A1 or Class 1 misdemeanor | 1 |
| Current offense committed while on probation/parole/post-release supervision or while incarcerated | +1 |
| All elements of current offense are elements of a prior offense | +1 |

**Consolidation rule:** when multiple convictions arise from the same court session or within a single week, only the highest-point conviction counts toward the prior record level — a critical defense tool for minimizing point exposure.

Point totals map to six Prior Record Levels:

| Level | Points |
|---|---|
| I | 0–1 |
| II | 2–5 |
| III | 6–9 |
| IV | 10–13 |
| V | 14–17 |
| VI | 18+ |

## Felony Sentencing Grid — Disposition Types

The sentencing grid cell at the intersection of offense class and prior record level specifies:

- **A (Active)** — incarceration required
- **I (Intermediate)** — supervised probation with additional conditions (house arrest, electronic monitoring, drug treatment, community service)
- **C (Community)** — non-incarcerative punishment (unsupervised probation, fines, community service)

When a cell shows multiple options (e.g., "C/I/A"), the judge may select any available disposition. Defense advocacy focuses on achieving the least restrictive disposition available in the cell.

## Sentence Ranges — Three Tiers

Within each grid cell, the statute provides three minimum-sentence ranges:

| Range | When applied |
|---|---|
| **Mitigated** (lowest) | Court finds mitigating factors substantially outweigh aggravating factors |
| **Presumptive** (middle) | Default; no substantial imbalance of aggravating/mitigating factors |
| **Aggravated** (highest) | Court finds aggravating factors substantially outweigh mitigating factors |

Maximum sentences are set by statute as a fixed ratio to the minimum (e.g., 120% of minimum + 9 months for most classes).

## Aggravating Factors (G.S. 15A-1340.16)

The State bears the burden of proving aggravating factors **beyond a reasonable doubt**. Selected factors:

- Defendant was a leader or organizer
- Offense involved multiple participants
- Heinous, atrocious, or cruel manner of commission
- Defendant used a weapon
- Victim was particularly vulnerable (elderly, young, disabled)
- Offense committed while on pretrial release
- Criminal gang involvement
- Position of trust exploitation
- Significant monetary harm
- Targeting a public official or law enforcement officer

**Defense note:** the same fact used to prove an element of the offense cannot also be used as an aggravating factor (anti-double-counting rule). Defense counsel should scrutinize each aggravating factor claim.

## Mitigating Factors (G.S. 15A-1340.16)

The defendant bears the burden of proving mitigating factors by **a preponderance of the evidence**. Selected factors — each a defense advocacy opportunity:

- Defendant played a minor or passive role
- Coercion, duress, or compulsion
- Defendant's mental or physical condition reduced culpability
- Defendant's youth and immaturity
- Defendant made substantial restitution
- Defendant cooperated with law enforcement
- Voluntary participant victim (age 16+)
- Strong provocation
- Good character and community reputation
- Prior military service
- Acceptance of responsibility
- Enrollment in or completion of treatment program
- Family support responsibilities
- Positive employment history

Defense strategy: present multiple mitigating factors to achieve the mitigated range and, where the grid permits, a community or intermediate disposition.

## Special Sentencing Enhancements (Outside Standard Grid)

| Enhancement | Statute | Effect |
|---|---|---|
| Firearm/deadly weapon | G.S. 15A-1340.16A | +72 months (Class A–E), +36 (F–G), +12 (H–I) minimum |
| Bulletproof vest use | G.S. 15A-1340.16C | Elevates offense one class |
| Criminal gang activity | G.S. 15A-1340.16E | One class higher; two classes for leaders (cap: Class C) |
| Identity concealment | G.S. 15A-1340.16G | Elevates one class; requires active imprisonment |
| Methamphetamine manufacturing with vulnerable persons | G.S. 15A-1340.16D | Enhanced sentences |
| Habitual felon | G.S. 14-7.1 | Up to four class levels higher (never above Class C); separate indictment required |
| Violent habitual felon | G.S. 14-7.7 | Life without parole |
| Sex offender recidivist | G.S. 14-27.23 | Class B1 minimum regardless of underlying class |

## Misdemeanor Classification

| Class | Severity |
|---|---|
| A1 | Most serious (e.g., assault on female, child abuse) |
| 1 | Serious (e.g., assault inflicting serious injury) |
| 2 | Moderate (e.g., simple assault) |
| 3 | Least serious (e.g., disorderly conduct) |

## Prior Conviction Levels — Misdemeanors

Misdemeanor prior record uses three levels based on total prior convictions (felony or misdemeanor each count as one):

| Level | Prior Convictions |
|---|---|
| I | No prior convictions |
| II | 1–4 prior convictions |
| III | 5+ prior convictions |

**Key distinction from felonies:** misdemeanor prior record counts every conviction; felony prior record uses a weighted point system.

## Misdemeanor Sentencing

Each misdemeanor grid cell provides one sentence range (days). The judge selects a term within the range. Dispositions (A/I/C) apply similarly to the felony grid.

Example — Class A1 misdemeanor assault on female:
- Level I: 1–60 days
- Level II: 1–75 days
- Level III: 1–150 days

## DWI Sentencing — Separate Framework (G.S. 20-179)

DWI offenses under G.S. 20-138.1 are not sentenced under the structured sentencing grid. Instead, G.S. 20-179 creates six sentencing levels based on **grossly aggravating**, **aggravating**, and **mitigating** factors:

### Grossly Aggravating Factors (most weight)

- Prior DWI conviction within 7 years
- DWI conviction after current offense date but before sentencing (contemporaneous)
- Child under 18, disabled, or developmentally disabled passenger (automatic Level 1)
- Serious injury to another person caused by impaired driving

### DWI Sentencing Levels

| Level | Trigger | Jail Range | Fine |
|---|---|---|---|
| Aggravated Level 1 | 3+ grossly aggravating factors | 12–36 months (mandatory 120 days + 120 days abstinence) | up to $10,000 |
| Level 1 | 2 grossly aggravating OR vulnerable passenger | 30 days–2 years (min 30 days OR 10 days + 120-day abstinence) | up to $4,000 |
| Level 2 | 1 grossly aggravating factor | 7 days–1 year (min 7 days OR 90-day abstinence) | up to $2,000 |
| Level 3 | Aggravating substantially outweigh mitigating | 72 hours–6 months (suspendable) | up to $1,000 |
| Level 4 | Aggravating and mitigating roughly balance | 48 hours–120 days (suspendable) | up to $600 |
| Level 5 | Mitigating substantially outweigh aggravating | 24 hours–60 days (suspendable) | up to $200 |

### DWI Aggravating Factors (lesser weight than grossly aggravating)

- Gross impairment (BAC ≥ 0.15)
- Especially reckless or dangerous driving
- Negligent driving causing accident
- Driving while license revoked for impaired driving
- Two or more prior moving violations within 5 years
- Speeding 30+ mph over limit while fleeing law enforcement

### DWI Mitigating Factors

- Slight impairment (BAC ≤ 0.09)
- Safe and lawful driving except for impairment
- Lawful BAC impairment (prescribed medication)
- Voluntary submission to DWI assessment prior to trial
- Completion of ADETS or substance abuse treatment
- No prior DWI convictions in 7 years

**Defense note:** the State must prove aggravating factors beyond a reasonable doubt; the defendant proves mitigating factors by a preponderance. Achieving Level 5 allows suspension of nearly all jail time.

## Habitual Felon — Defense Considerations

A habitual felon indictment requires a **separate indictment** naming the three prior qualifying felony convictions, each with:
- Date of offense
- Jurisdiction
- Date of plea or conviction
- Court identity

Defense challenges: challenge the validity of prior convictions (constitutional right to counsel, voluntariness of prior pleas), dispute the classification of prior offenses, and ensure the separate indictment is properly served and timed. When habitual felon status is established, only the convictions used for habitual status are excluded from prior record level — the rest still count.

## Practical Defense Strategies

1. **Challenge prior record points:** scrutinize documentation; dispute misclassified offenses; invoke the consolidation rule for same-session convictions.
2. **Load mitigating factors:** present all applicable mitigating evidence; even one well-supported factor shifts toward the mitigated range.
3. **Contest aggravating factors:** force the State to prove each beyond a reasonable doubt; invoke anti-double-counting rule.
4. **Target disposition type:** where the grid offers C or I as options alongside A, build the record for the least restrictive disposition.
5. **DWI level strategy:** document mitigating factors (assessment completion, low BAC) before sentencing; challenge aggravating factor proof.
6. **Habitual felon defense:** attack the prior convictions; challenge the indictment's procedural requirements.
