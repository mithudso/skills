# Exhaustive User Experience (UX) Survey Item Repository

This document contains a comprehensive collection of survey items categorized by key UX dimensions. Each item includes a suggested scale format.

## 1. Ease of Use & Usability
* Overall, how easy was it to use this [Product/Service]? (Likert 1-5)
* It was simple to find what I was looking for. (Likert 1-5)
* The navigation menu is intuitive. (Likert 1-5)
* I felt comfortable using this [Product/Service] right away. (Likert 1-5)
* The steps required to complete a task were logical. (Likert 1-5)
* I found the interface to be cluttered. (Likert 1-5, Reverse Scored)
* The system was easy to learn. (Likert 1-5)
* I can use this [Product/Service] without any instructions. (Likert 1-5)
* How would you rate the effort required to complete your task? (1 = Very Low Effort, 5 = Very High Effort)
* I found the [Product/Service] unnecessarily complex. (Likert 1-5)
* The various functions in this system were well integrated. (Likert 1-5)
* I thought there was too much inconsistency in this system. (Likert 1-5)
* I would imagine that most people would learn to use this system very quickly. (Likert 1-5)
