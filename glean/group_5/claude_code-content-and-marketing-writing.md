# Content, Marketing & External Communications

## Cross-hub note

One of five writing-family hubs. Route to sibling when task not external-content craft:

- **`writing-expert`** — general prose, voice, style, tone, multi-pass editing, rhetoric, headlines, plain language. Default for any writing not domain-specific.
- **`technical-writing-craft`** — software docs, API references, how-tos, tutorials, runbooks, knowledge-base articles.
- **`executive-comms`** — C-suite/board/VP audiences, BLUF, decision memos, status reports, persuasion, business decks.
- **`career-and-formal-writing`** — résumés, cover letters, performance reviews, academic/citation writing, legal-adjacent and policy/governance prose.

Task straddles two hubs (e.g. launch blog needing executive framing, support reply needing plain-language accessibility): start here for content structure, pull sibling hub for specialized layer.
