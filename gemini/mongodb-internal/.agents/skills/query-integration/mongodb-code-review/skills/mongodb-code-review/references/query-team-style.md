# Query Team Style Guidelines

Reference for query team C++ and JS code. Refer to the style guides linked in the table below, using the glean mcp to access the google doc.

## Style Guide Links

When flagging a style violation, include a link to the relevant style guide so the author can read the full rationale:

| Topic | Link |
|---|---|
| Query-team-specific rules (this document's source) | [Query Team Style Guidelines](https://docs.google.com/document/d/1nBq0ZLHJTqSwsFqqxWqQRYH4OFVG-5ZzP-QB-_PDu_w) |
| General C++ style | [Server C++ Style Guide](https://github.com/mongodb/mongo/blob/master/docs/cpp_style.md) |
| Code comment conventions | [Query Team Code Comment Guidelines](https://docs.google.com/document/d/1YPGwQfugv9tkK6I8jL9FCbPesJIOQjccHtrvPsSCJDM) |
| Includes, license, basics | [Server Code Style Wiki](https://github.com/mongodb/mongo/wiki/Server-Code-Style) |

Example:
```
**[mongodb-code-review · style-review]** [style] Constants should use `k` prefix, not `UPPER_SNAKE`.
See [Query Team Style Guidelines § Naming](https://docs.google.com/document/d/1nBq0ZLHJTqSwsFqqxWqQRYH4OFVG-5ZzP-QB-_PDu_w).
```
