## Key Acronyms
- **STB**: Straight To Base
- **A/B**: Acid / Base extraction
- **FASA / FASI / FASW**: Fumaric Acid Saturated Acetone / IPA / Water
- **MHRB**: Mimosa Hostilis Root Bark
- **NPS**: Non-Polar Solvent (e.g., Naphtha, Heptane, Limonene)
